📖 名词释义库

MoE（混合专家模型）一种模型架构，通过组合多个专门化的子模型（专家）来处理不同任务，提升效率和性能。
VPD（垂直供电）一种电源架构，通过垂直方向直接向处理器供电，减少传输损耗，适用于高功耗AI芯片。
IVR（集成电压调节器）将电压调节功能集成到芯片内部或附近，提高供电效率和响应速度，常用于数据中心。
越狱（Jailbreaking）绕过AI模型安全限制的技术手段，使模型执行本被禁止的操作。
