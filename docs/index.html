📖 名词释义库

混合架构指模型同时使用多种注意力机制（如线性注意力+传统注意力），在保持性能的同时降低计算复杂度。
Agent Native Cloud云服务的一种新形态，将智能体（Agent）作为云基础设施的原生能力，企业可以直接在云上构建和部署AI智能体。
垂直供电（VPD）一种电源架构，通过穿透电路板垂直输送电力到处理器下方，缩短传输距离，降低损耗，适用于高功耗AI芯片。
后训练（Post-training）在模型预训练完成后，通过监督微调（SFT）和强化学习（RL）等步骤进一步优化模型特定能力的过程。
