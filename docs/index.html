📖 名词释义库

【HBM】：高带宽存储器，一种将多个DRAM芯片垂直堆叠，实现超高数据传输速度的尖端内存技术，是AI大模型训练和推理的关键部件。
【ABF】：味之素堆积膜，一种由日本味之素公司开发的绝缘薄膜材料，因其优异的性能，被广泛应用于高性能AI芯片的先进封装中，是当前芯片供应链的“卡脖子”材料之一。
【Token】：在AI领域，Token是模型处理文本的最小单位，可以是一个词、一个字或一个标点。用户调用AI服务时，消耗的Token数量直接决定了成本，因此Token正成为一种新的计价单位。
【具身智能】：指能够感知物理世界、理解指令并执行物理操作的智能体，如人形机器人。其核心在于将“大脑”（AI算法）与“身体”（机器人硬件）结合。
【超少样本学习】：一种机器学习方法，旨在让模型仅通过极少量的数据样本（如3-5条）就能学会并执行新任务，极大地降低了对海量标注数据的依赖。
【Chiplet】：芯片粒技术，将一个大而复杂的芯片拆分成多个更小、更简单的芯片模块（Chiplet），再通过先进封装技术将它们组合在一起，以提升良率、降低成本并实现异构集成。
【韬（τ）定律】：华为提出的半导体发展新思路，主张通过系统级协同优化（如3D堆叠、先进封装）来提升芯片整体性能，而非单纯追求晶体管尺寸的缩小，以应对摩尔定律放缓的挑战。
【PUE】：电能利用效率，是衡量数据中心能源效率的关键指标。PUE值越接近1，表示数据中心的电能越高效地用于IT设备，而非冷却等辅助设施。
