📖 名词释义库

【物理AI】：指能够感知、理解并与物理世界进行交互的人工智能系统，如工业机器人、自动驾驶汽车等，它不仅能“思考”，更能“行动”。
【世界模型】：一种能够模拟真实物理世界运行规律的AI模型，通过在虚拟环境中进行试错和推演，为机器人在现实中的决策提供依据，降低真实试错成本。
【VLA】：视觉-语言-动作（Vision-Language-Action）模型的缩写，一种将视觉感知、语言理解和动作执行融合为一体的AI架构，是实现具身智能的关键技术。
【HBM】：高带宽存储器（High Bandwidth Memory），一种通过3D堆叠技术将多个DRAM芯片垂直连接，实现超高数据传输速度的内存，是AI服务器GPU的核心配套芯片。
【DRAM】：动态随机存取存储器（Dynamic Random Access Memory），是计算机和服务器中最常见的主内存，用于临时存储正在运行的程序和数据。
【Seedance 2.0】：字节跳动发布的新一代视频生成大模型，能够在15秒内生成多镜头、电影级画质的视频，对影视内容创作行业产生革命性冲击。
【具身智能】：指能够在物理世界中拥有身体（如机器人）并与之交互的智能体，是AI从虚拟走向现实的关键一步。
【价值观对齐】：指确保AI模型的目标、行为和决策与人类的价值观、伦理规范和社会期望保持一致，防止AI产生有害或偏差行为。
