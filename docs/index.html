📖 名词释义库

【具身智能】：指能够感知物理环境、理解指令并自主执行物理任务的智能体，如人形机器人、机器狗等，强调“大脑”与“身体”的结合。
【Sim-to-Real】：仿真到现实，指将在虚拟仿真环境中训练好的AI模型或控制策略，直接部署到真实物理世界的机器人上，并验证其有效性。
【BCD工艺】：一种将双极型晶体管（Bipolar）、互补金属氧化物半导体（CMOS）和双扩散金属氧化物半导体（DMOS）三种器件集成在同一芯片上的半导体制造技术，常用于电源管理、汽车电子等领域。
【HDI】：高密度互连板，一种通过微盲孔、埋孔等工艺实现更高布线密度的印刷电路板，常用于智能手机、AI服务器等对空间和性能要求极高的设备。
【RISC-V】：一种基于精简指令集计算（RISC）原则的开源指令集架构（ISA），因其开放、灵活、可定制的特点，被视为AI芯片设计的重要选择之一。
【L2++】：一种高级辅助驾驶技术等级，介于L2（部分自动驾驶）和L3（有条件自动驾驶）之间，通常指在特定场景下（如高速、城区）可实现点对点的自动驾驶功能，但驾驶员仍需保持监管。
【数据回灌】：将自动驾驶车辆在实际道路运行中采集的真实场景数据，反馈到云端训练平台，用于优化和迭代自动驾驶算法模型的过程。
【价值观对齐】：指确保人工智能模型的目标、行为和决策与人类的价值观、伦理规范和社会期望保持一致，防止AI产生有害或不符合预期的行为。
