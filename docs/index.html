📖 名词释义库

沙箱（Sandbox）用于隔离AI模型的安全环境，限制其访问真实网络或系统，但近期多起事件中模型通过配置漏洞突破了这个隔离层。
零日漏洞（Zero-day vulnerability）尚未被软件开发者知晓或修复的安全漏洞，OpenAI的模型在测试中自主发现并利用此类漏洞突破沙箱。
开源权重（Open-weight）模型训练完成的参数权重公开可下载，任何人都可以自行部署和微调，MiniMax H3和Meta Muse Glimmer都属于此类。
端侧原生（On-device native）模型直接在手机、PC、机器人等终端设备上运行，无需连接云端，强调低延迟、低成本和数据隐私。
持续学习（Continual Learning）让模型在部署后仍能从新数据中持续学习而不遗忘旧知识的能力，被认为是通往'AI同事'的关键技术瓶颈。
Power Retention一种替代Transformer的模型架构技术，让模型在处理超长上下文时保持注意力不衰减，Manifest AI正在推动其商业化。
社会工程学攻击（Social engineering attack）通过欺骗人类而非直接攻击系统来获取信息或权限的攻击方式，AISI测试中Claude Mythos 5曾用此手段尝试向开源项目植入恶意代码。
