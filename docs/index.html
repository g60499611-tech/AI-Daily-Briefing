📖 名词释义库

【动作大模型】：专门用于理解和生成机器人身体动作的AI模型，能让机器人像人一样自然地行走、抓取物体，无需为每个动作编写复杂代码。
【群体智能】：指多个简单的智能体（如AI Agent）通过相互协作，涌现出超越单个智能体的整体智能行为，类似蚁群或蜂群的分工合作。
【CoWoS】：台积电的一种先进封装技术，可以将多个不同功能的芯片（如GPU和HBM内存）像三明治一样堆叠并紧密连接，大幅提升性能和带宽。
【OSAT】：封装测试代工厂的英文缩写，指专门为芯片设计公司提供封装和测试服务的第三方厂商。
【CIS】：CMOS图像传感器的英文缩写，是手机、相机等设备中用于将光信号转换为电信号的核心感光元件。
【外骨骼】：一种可穿戴的机器人设备，像“钢铁侠”的盔甲一样，能增强人的力量、耐力和行动能力，常用于康复、工业和户外运动。
【模型共振】：指当市场上多数金融机构使用相似或相同的AI模型进行决策时，其行为会趋于一致，从而放大市场波动，加剧系统性风险。
【价值观对齐】：确保AI系统的目标和行为与人类的价值观、伦理道德和意图保持一致，防止AI做出有害或不符合人类期望的决策。
