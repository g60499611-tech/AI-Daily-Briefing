📖 名词释义库

【Agent/智能体】：一个能够自主理解、规划和执行复杂任务的AI程序，可以看作是拥有“大脑”的AI助手，能主动帮你完成订餐、安排行程等具体工作。
【模型共振】：指当大量金融机构使用相似的AI模型进行决策时，面对同一市场信号会做出高度一致的反应，从而加剧市场波动和系统性风险。
【晶圆级芯片（WSE）】：一种将整个晶圆（通常用于切割成数百个独立芯片的圆形硅片）直接做成一个超大芯片的技术，能提供远超传统芯片的计算能力，主要用于训练超大规模AI模型。
【价值观对齐】：指确保AI模型的目标、行为和价值观与人类的伦理道德、社会规范保持一致，防止AI产生有害或不符合预期的行为。
【算法黑箱】：指AI模型的内部决策过程极其复杂且不透明，人类难以理解其为何得出某个特定结论，这给监管和追责带来了巨大挑战。
【深度伪造】：利用AI技术（特别是生成对抗网络）合成高度逼真的虚假图像、音频或视频，常被用于制造假新闻、进行诈骗或诽谤。
【H-Oil技术】：一种先进的沸腾床渣油加氢工艺，能将石油提炼后剩下的重质渣油高效转化为轻质油品，提升资源利用率并降低能耗。
【SDPA商品】：指由大模型识别并填充的、用于私信咨询场景下的虚拟商品或服务描述，帮助商家在非交易链路中更精准地触达和转化潜在客户。
