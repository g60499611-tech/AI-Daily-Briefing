隐空间世界模型一种不直接预测像素画面，而是在抽象表征空间学习动作与状态因果关系的世界模型，更接近人类对物理世界的理解方式。

混合专家模型（MoE）一种模型架构，将任务分配给多个专门的‘专家’子网络处理，只激活部分参数，从而在保持性能的同时降低计算成本。
无编码器多模态模型一种直接处理文本、图像、音频等多种输入的统一模型，无需为每种模态配备独立的编码器，从而降低延迟和内存占用。
