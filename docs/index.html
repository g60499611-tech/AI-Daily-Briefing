📖 名词释义库

蒸馏（Distillation）将大型模型的能力压缩到更小、更快的模型中，通过让小型模型学习大型模型的输出，在保持性能的同时大幅降低计算成本。
MCP（Model Context Protocol）模型上下文协议，一种允许AI代理与外部工具和服务（如交易系统、数据库）交互的标准接口。
递归自我改进AI系统能够自主设计、运行和迭代实验来改进自身或相关模型的能力，是通向通用人工智能的关键技术路径。
显隐双轨标识中国AI内容标识体系：显式标识（用户可见的角标、提示）和隐式标识（嵌入文件元数据，供机器识别和追溯）。
代码混合（Code-mixing）在单句话中混合使用多种语言的现象，在印度等 multilingual 地区非常普遍，对AI语音系统构成挑战。
GEO（生成引擎优化）通过生成大量虚假内容来操纵AI大模型搜索结果的技术，类似于传统SEO但针对AI模型。
