📖 名词释义库

World Model（世界模型）让AI不仅理解文字，还能模拟和推演物理世界的变化，是具身智能、机器人和自动驾驶的底层操作系统。
GEO（生成式引擎优化）通过大量发布虚假或误导性内容，操纵AI大模型在搜索和问答中的输出结果，类似传统SEO但针对AI。
LoRA（低秩适配）一种高效的模型微调技术，只需调整少量参数就能让大模型适应新任务，大幅降低计算成本。
VPD（垂直供电）一种新型芯片供电架构，通过缩短电力传输距离来降低损耗，应对AI芯片功耗飙升的挑战。
MaaS（模型即服务）将AI模型通过API接口以服务形式提供给客户，按使用量收费，是当前大模型商业化的主流模式。
