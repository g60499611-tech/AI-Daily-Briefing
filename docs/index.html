📖 名词释义库

【JEPA】：由Yann LeCun提出的“联合嵌入预测架构”，是一种不逐像素预测，而是在抽象表征层面进行学习和预测的AI模型，旨在提升模型的泛化能力和学习效率。
【NPU】：神经网络处理单元，一种专门为加速人工智能（尤其是神经网络）计算而设计的处理器，相比通用GPU，在特定AI任务上能效比更高。
【PUE】：电能利用效率，是衡量数据中心能源效率的指标，其值为数据中心总能耗与IT设备能耗之比，越接近1代表能效越高。
【MaaS】：模型即服务，一种将AI模型通过API接口提供给用户使用的商业模式，用户无需自己训练和部署模型，按需调用即可。
【ARR】：年度经常性收入，衡量订阅制或服务合同模式下，每年可稳定重复获得的收入，是评估SaaS公司健康度的重要指标。
【Scaling Law】：规模定律，指在AI领域，随着模型参数、数据量和计算量的增加，模型性能会持续提升的观察规律。
【具身智能】：指能够感知物理环境、进行自主规划并执行物理动作的智能体，如人形机器人、自动驾驶汽车等，强调“身体”与“大脑”的结合。
【事实性幻觉】：指AI模型在生成内容时，编造或输出与事实不符的信息，尤其在医疗、法律等对准确性要求极高的领域，这是需要重点解决的问题。
