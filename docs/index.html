📖 名词释义库

MoE（混合专家模型）一种模型架构，将多个'专家'子网络组合在一起，每次只激活部分专家来处理输入，从而在保持高性能的同时降低计算成本。Kimi K3使用了896个专家、每次激活16个的MoE架构。
上下文窗口模型一次能处理的文本长度，单位是token。100万token的上下文窗口意味着模型可以一次性阅读和理解相当于多本厚书的内容。
后训练在模型预训练完成后，通过监督微调（SFT）和强化学习（RL）等步骤进一步优化模型在特定任务上的表现。微博VibeThinker的后训练成本仅7800美元。
推理成本模型在运行时（如回答用户问题）消耗的计算资源，通常以每百万token的价格衡量。这是决定AI服务商业可行性的关键指标。
端侧AI在本地设备（如手机、IoT设备）上运行AI模型，而非依赖云端服务器。优势是低延迟、高隐私、低功耗，但受限于设备算力。
