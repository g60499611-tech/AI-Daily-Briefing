Agentic推理指AI模型在需要多轮交互、工具调用和长上下文的智能体（Agent）场景下进行推理的过程，与传统的单轮问答不同。

世界动作模型（WAM）一种联合学习未来世界状态和机器人动作的AI模型，旨在让机器人更好地理解和执行物理世界中的任务。

Harness在AI Agent语境下，指围绕模型构建的执行框架或工具链，负责规划、记忆、调度等，以完成复杂任务。
