📖 名词释义库

开放权重（Open Weights）模型发布方公开训练好的参数权重，允许用户下载、微调和本地部署，但不一定公开训练代码和数据。
MoE（混合专家架构）一种模型架构，将模型拆分为多个'专家'子网络，每次推理只激活部分专家，在降低算力成本的同时保持模型能力。
VLA（视觉语言动作模型）融合视觉、语言和动作控制的模型，让机器人能理解自然语言指令并执行物理操作。
零日漏洞（Zero-Day Vulnerability）尚未被开发者发现且没有官方补丁的安全缺陷，被利用时往往无法防御。
端侧AI在手机、PC、机器人等终端设备上直接运行AI模型，无需将数据上传到云端处理。
后训练（Post-training）基础模型训练完成后，通过微调、强化学习等方式继续优化模型表现，是当前模型快速迭代的主要手段。
