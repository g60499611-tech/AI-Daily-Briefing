📖 名词释义库

MCP (Model Context Protocol)模型上下文协议，一种让AI模型与外部工具安全交互的标准化协议，类似AI界的'USB接口'。
长程任务 (Long Horizon Task)需要模型在数周甚至数月内持续规划、执行和调整的复杂任务，区别于单次问答。
自主智能体系统 (Autonomous Agent System)能够独立感知环境、制定计划、执行操作并自我纠错的AI系统，无需人类持续干预。
VLA (Vision-Language-Action)视觉-语言-动作模型，一种能同时理解视觉输入、语言指令并生成物理动作的AI模型，常用于机器人。
R2R-CE (Room-to-Room Continuous Environment)机器人导航领域的标准基准测试，评估AI在连续环境中根据语言指令导航到目标位置的能力。
DSA (Digital Services Act)欧盟《数字服务法案》，对大型科技平台的内容审核、算法透明度和用户保护提出严格要求的法规。
