📖 名词释义库

【MoE（混合专家模型）】：一种模型架构，将一个大模型拆分成多个“专家”子网络，每次处理任务时只激活其中一部分专家，从而在扩大模型能力的同时控制计算成本。
【GRPO算法】：一种强化学习算法，通过比较模型生成的一组候选答案的平均水平来优化模型，无需依赖额外的价值模型，能更高效地提升模型的推理能力。
【数推分离】：一种创新的模型架构，将负责逻辑推理的“推理网络”和负责学习新数据的“数据学习网络”分开，使模型能持续学习而不影响原有推理能力。
【光计算芯片】：利用光子而非电子进行信息处理的芯片，具有传输速度更快、功耗更低、带宽更大的优势，被视为突破传统电子芯片算力瓶颈的潜在技术路径。
【异构算力】：指在一个系统中混合使用不同类型的计算单元（如CPU、GPU、NPU等）来协同工作，以满足AI训练和推理中多样化的算力需求。
【模型共振】：指当大量金融机构使用同质化的AI模型时，面对相同市场信号会做出相似决策，导致市场行为趋同，加剧市场波动和顺周期风险的现象。
【价值观对齐】：指确保AI模型的目标、行为和决策与人类的价值观、伦理规范和社会期望保持一致，防止AI产生有害或不符合预期的行为。
【全模态】：指AI模型能够同时处理和理解多种类型的数据，如文本、图像、语音、视频、音乐等，实现更全面、更自然的交互和内容生成能力。
