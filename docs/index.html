📖 名词释义库

MoE（混合专家模型）一种模型架构，将模型拆分为多个‘专家’子网络，每次推理只激活部分专家，从而在保持大模型能力的同时降低计算成本。
Token大模型处理文本的最小单位，可以是一个词、一个子词或一个字符。模型按Token数量收费，Token越多成本越高。
分词器（Tokenizer）将原始文本切分成Token的算法。不同分词器对同一段文本产生的Token数量不同，直接影响模型使用成本。
VPD（垂直供电）一种新型芯片供电架构，通过穿透电路板垂直向上输送电力，缩短传输距离，降低功耗和延迟，适用于高功耗AI芯片。
脑磁图（MEG）一种无创测量大脑磁场活动的技术，用于脑机接口研究中解码大脑信号。
