📖 名词释义库

VLAVision-Language-Action的缩写，视觉-语言-动作模型，让机器人通过视觉和语言理解指令并执行物理动作的AI架构。
世界模型一种能够学习并预测世界状态如何随时间变化的AI模型，不局限于特定任务，而是建立对物理世界运行规律的通用理解。
推理芯片专门为AI模型推理（即处理用户输入并生成输出）而设计的芯片，相比训练芯片更注重低延迟和低功耗。
FSDPFully Sharded Data Parallel的缩写，一种分布式训练技术，将模型参数、梯度和优化器状态分片到多个GPU上，以支持超大模型训练。
OODOut-of-Distribution的缩写，分布外测试，指在模型训练时未见过的场景或物体上测试其泛化能力。
FDEFrontier Deployment Engineer的缩写，前沿部署工程师，驻场在客户现场，将通用AI模型集成到客户真实业务流程中的技术角色。
