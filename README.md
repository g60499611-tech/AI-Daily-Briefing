# AI 周中简报与周报

一个基于 Python、Tavily、DeepSeek 和 GitHub Actions 的自动化 AI 资讯筛选与推送工作流。

系统在每周三、周日自动检索指定周期内的中英文 AI 新闻，经过信源过滤、事件去重、分类、五维评分和摘要生成后，以 HTML 邮件推送，并同步发布到 GitHub Pages。

## 核心流程

```text
GitHub Actions 定时触发
→ Tavily 中英文新闻检索
→ 权威信源过滤与 URL 去重
→ DeepSeek 事件级语义去重、分类和评分
→ Python 复算分数、应用门槛并排序
→ HTML 邮件推送
→ GitHub Pages 发布
```

## 功能

- 权威信源检索：3 类中英文关键词覆盖产品商业、政策治理和模型算法
- 周期简报：周三汇总周一至周三，周日汇总周一至周日
- 事件级处理：合并同一事件的重复报道，优先保留一手或更权威来源
- 五维评分：按行业影响力、新颖性、可信度、读者相关性和时效性排序
- 数量控制：每个板块最多 3 条，总数最多 9 条，不足时不强行凑数
- 趋势提炼：生成板块趋势、本期信号、行业总览和名词释义
- 多渠道交付：同时生成响应式 HTML 邮件和 GitHub Pages 页面
- 自动运行：每周三、周日北京时间 20:00 执行，也支持手动触发
- 安全处理：转义模型生成的 HTML 内容，并校验外部链接协议

## 内容板块

1. 产品与商业
2. 政策与治理
3. 模型与算法

每个板块按照事件总分降序展示，最多保留 3 条。

## 搜索主题

- 产品与商业：产品发布、融资、收购、商业合作
- 政策与治理：政策、监管、立法、安全伦理
- 模型与算法：模型发布、开源项目、算法突破

每个主题分别执行中文和英文检索，并按本期北京时间日期窗口过滤结果。

## 信源规则

系统使用三级信源白名单，以下列表与当前代码配置保持一致。

### 一手来源

同一事件优先采用官方发布或原始公告：

- OpenAI
- Anthropic
- Mistral
- Meta AI
- Google Blog
- Google DeepMind
- Microsoft Blogs

### 核心媒体

没有更合适的一手材料，或需要独立报道时采用：

- 新华网、人民网、财新网
- 机器之心、量子位
- Reuters、Bloomberg、TechCrunch
- The Information、MIT Technology Review、Ars Technica

### 补充来源

仅在一手来源和核心媒体覆盖不足时采用：

- 36氪、亿欧
- VentureBeat、Wired、SemiAnalysis

非白名单来源不进入最终简报。公司官方材料适合确认发布事实，但模型仍需区分事实信息与宣传性表述。

## 事件评分

每个候选事件按 100 分制评分：

| 维度 | 满分 |
|---|---:|
| 行业影响力 | 30 |
| 变化与新颖性 | 20 |
| 事实可信度 | 20 |
| 读者相关性 | 20 |
| 时效性 | 10 |

系统会对宣传稿、标题夸张、匿名传闻和缺少发布时间等情况扣分。Python 会重新计算总分，不直接采用模型自报的总分。

- 总分低于 55：不收录
- 可信度低于 10：不收录
- 本期信号候选：总分至少 80、行业影响力至少 24、可信度至少 15

评分仅用于内部筛选，目前不在邮件正文中展示。

## 定时规则

| 运行方式 | 北京时间 | 检索范围 |
|---|---|---|
| 周中简报 | 每周三 20:00 | 本周一至周三 |
| AI 信息周报 | 每周日 20:00 | 本周一至周日 |
| 手动触发 | 随时 | 可选择自动、周中或周报模式 |

## 配置

在 GitHub Actions Secrets 中配置：

| Secret | 用途 |
|---|---|
| `TAVILY_API_KEY` | Tavily 新闻检索 |
| `DEEPSEEK_API_KEY` | DeepSeek 去重、分类、评分和总结 |
| `EMAIL_ACCOUNT` | QQ 邮箱账号及默认收件地址 |
| `EMAIL_AUTH_CODE` | QQ 邮箱 SMTP 授权码 |

## 手动运行

在 GitHub Actions 中选择“AI周中简报与周报推送”，点击 **Run workflow**：

- `auto`：周日生成周报，其他日期生成周中简报
- `midweek`：强制生成周中简报
- `weekly`：强制生成本周周报

也可以在本地运行：

```bash
pip install -r requirements-gh.txt
python main.py --email your@qq.com --output index.html --report-type midweek
```

## 测试

```bash
python -m unittest discover -s tests -v
```

测试覆盖北京时间窗口、板块顺序、数量限制、事件评分与排序、收录门槛、HTML 转义和安全链接。
